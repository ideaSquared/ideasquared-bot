# Security policy

## Reporting a vulnerability

Please report vulnerabilities privately through GitHub:
[report a vulnerability](https://github.com/ideaSquared/ideasquared-bot/security/advisories/new).

Do not open a public issue or pull request for a security problem, and do not include secrets or tokens in a report.

## What to expect

- We acknowledge a report within 3 working days.
- We confirm whether it is a vulnerability and share a plan or timeline within 10 working days.
- We credit reporters in the advisory unless they prefer to stay anonymous.

Only the latest commit on `master` (the version that is deployed) is supported.
